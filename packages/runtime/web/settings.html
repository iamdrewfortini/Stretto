Model API key

Paste your Meta Model API key. It is saved to ~/.config/humanflow/runtime.env (mode 600, outside the repo) and never displayed, logged or sent anywhere except the gateway's own calls to api.meta.ai. Loopback only. The gateway starts without a key; model features stay off until one is saved here, and a saved key takes effect immediately, no restart needed.

Privacy: what may be sensed

Nothing is sensed until you turn a source on here. This page is the acceptance step: the sensors start from deny-everything, a grant lasts only as long as you choose, and turning a source off stops sampling on the next tick. Only counts are ever recorded: keys and clicks as numbers, never what was typed, no screen pixels, no audio.
